# Semantic Search Frontend

A clean, professional React + Tailwind CSS frontend for semantic search.

## Setup

```bash
npm install
npm start
```

## Features

- **Login Page**: Clean authentication interface
- **Dashboard**: File upload (drag-and-drop) and search
- **Theme Toggle**: Light/dark mode with persistence
- **Responsive**: Works on all devices
- **Professional**: Minimal, academic-suitable design

## Usage

1. Enter any credentials on login
2. Upload files via drag-and-drop or file picker
3. Search documents with semantic queries
4. Toggle theme in top-right corner

Built with React 18, Tailwind CSS, and Lucide React icons.
